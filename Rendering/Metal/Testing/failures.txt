Metal volume image-compare failures (run: Aug 05 2026, full RenderingVolumeCxx-Metal suite)

Gradient opacity no longer depends on shading being enabled: the Metal backend
was gating UseGradientOpacity on property->GetShade(), but the OpenGL backend
applies gradient opacity whenever the property declares it. This fixes
TestGPURayCastTwoComponentsGradient (0.4505 -> pass): previously the whole
right-half box rendered as a plain purple slab (gradient opacity skipped), the
baseline shows only the x=17 boundary plane sliver with gradient darkening at
the top/bottom edges.

Uniform-grid blanking and ghost-array support is now implemented in the Metal
volume ray-cast backend (cell/point ghost arrays are uploaded into a
cell-centered RG8 3D texture and skipped during the march, mirroring the
OpenGL backend's in_blanking texture + g_skip logic). This fixes
TestGPURayCastVolumeUniformGridBlanking (0.0706 -> 0.0001) and
TestGPURayCastVolumeGhostArrays (0.1646 -> pass). The blanking texture is now
built from the original dataset's ghost arrays (the cell-data effective-input
proxy carries only scalars), fixing TestGPURayCastVolumeGhostArraysCellData
(0.1630 -> pass).
