§2. SAMPLE-COUNT PPMs — App GL @ 1024
================================================================================
Method: VTK_METAL_TEST_GL_ITER=1 dumps g_currentT/4096 to red channel.
Iteration = red × 4096 / 255. 5 frames, first frame captured.

                  Covered     % total   Mean iter  Median  P95
App GL j0         421,828     40.2%     86.5       80.3    192.8
App GL j1         423,564     40.4%     86.7       80.3    192.8

  Raw red values: min=1  max=14  mean=5.39-5.40
  Top 5 red: [1:55k, 2:51k, 3:47k, 4:44k, 5:40k]  (smooth geometric decay)

KEY FINDING: j0 and j1 iteration counts are IDENTICAL.
  - Mean: 86.5 vs 86.7 (noise)
  - Coverage: 421,828 vs 423,564 (noise)
  - Distribution: identical shape

This means jitter does NOT add iterations. The +11 ms jitter cost on GL is
entirely a per-sample cost change (divergent memory access, cache behavior,
phase interaction with early-exit), NOT a trip-count change.

§3. MARCH_STEPS CAP VERIFICATION
================================================================================
VTK_METAL_TEST_MARCH_STEPS=1 + GL_ITER: mean iterations = 86.5 (not 1).
The cap did NOT bite. MARCH_STEPS is dead on GL — the env var is read but
does not constrain the march loop. The fixed-steps probe data in J0 dump
§3 is therefore uninterpretable for per-sample cost.

§4. HARNESS GL vs APP GL (the §2 discrepancy)
================================================================================
Harness GL (from HARNESS doc, single-run 2048/SD4):
  j0: 50.30 ± 4.97 ms  j1: 75.49 ± 5.99 ms  Δ: +25.19 ms

App GL (interleaved 1024):
  j0: 26.94 ± 0.83 ms  j1: 37.94 ± 1.66 ms  Δ: +11.00 ms

Harness GL Δ (+25.2) ≈ 2× App GL Δ (+11.0). The harness over-charges
GL jitter. This was the original §2 finding of the HARNESS doc. The harness
GL march is heavier than the app GL march (more per-step work = more
divergence penalty from jitter), or the harness GL semantics differ.

Harness GL PPMs not available — harness jitter_gap_repro.mm does not have
GL_ITER support (only GL_DUMP_PPM for color output).
